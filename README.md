# Psychiatric Services of the Rockies: Adult IOP

Single-page lead generation landing page for the Adult Intensive Outpatient Program (IOP) in Fort Collins, CO.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- Lead form posts to `/api/lead` (ready for CRM / GHL webhook wiring).
- Brand colors lean sage green with warm earth neutrals, consistent with the practice identity.
